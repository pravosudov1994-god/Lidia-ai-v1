# LIDIA AI

LIDIA AI — виртуальный AI-маркетолог для малого бизнеса.

Главная задача продукта: быстро разобрать бизнес пользователя, определить точки роста и предложить конкретные следующие шаги.

## MVP

- Премиальная главная страница LIDIA AI
- Отдельная страница AI-чата
- Быстрый маркетинговый разбор
- AI-роль «Лидия — маркетинговый директор»
- Подготовка к подключению OpenAI API
- Развёртывание на Cloudflare Workers

## Стек

- Next.js + TypeScript
- React
- CSS
- Cloudflare Workers
- OpenAI API (следующий этап)

## Статус

Первичная разработка MVP.
