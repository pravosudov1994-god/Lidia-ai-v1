# LIDIA AI

LIDIA AI — виртуальный AI-маркетолог для малого бизнеса.

Главная задача продукта: быстро разобрать бизнес пользователя, определить точки роста и предложить конкретные следующие шаги.

## MVP

- Премиальная главная страница LIDIA AI
- Отдельная страница `/chat`
- Реальный серверный AI-чат через OpenAI Responses API
- Системный промпт «Лидия — маркетинговый директор»
- Ограничения размера диалога для MVP
- Развёртывание через Cloudflare Workers

## Стек

- Next.js + TypeScript
- React
- CSS
- Cloudflare Workers
- OpenAI Responses API

## Переменные окружения

Для работы AI-чата серверу нужна переменная:

```text
OPENAI_API_KEY=<secret>
```

Опционально можно задать модель:

```text
OPENAI_MODEL=gpt-5.6
```

Никогда не добавляйте реальный API-ключ в GitHub. Для локальной разработки используйте `.env.local`, а в Cloudflare храните ключ как secret/environment variable.

Пример переменных есть в `.env.example`.

## Локальный запуск

```bash
npm install
npm run dev
```

После запуска откройте `http://localhost:3000`, а чат находится на `/chat`.
